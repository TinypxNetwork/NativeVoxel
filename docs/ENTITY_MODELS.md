# 扩展后的原生实体模型

`EntityModels::build` 已覆盖 33 个 1.8.9 生物/盔甲架协议类型，以及对象 1（船）、10（矿车）、78（盔甲架）。返回网格沿用脚下原点、Y 向上、正面 +Z 的约定；位置和身体 yaw 由调用方应用。API 与实体逻辑、网络、OpenGL 独立。

本轮补充狼、豹猫/猫、马/驴/骡/亡灵马、兔子、女巫、守卫者、凋灵、末影龙、盔甲架和蝙蝠，以及船和矿车。`tools/export_entity_models.py` 重新编译原始模型类，直接提取 12 组模型的 **172 个原始长方体**、UV、镜像、膨胀后的准确顶点边界和父子关系，生成 `src/entity_model_data.inc`。马的长段关节计算从原 `ModelHorse.setLivingAnimations` 作字段/函数映射，生成 `entity_horse_animation.inc`，避免手工抄录尺寸与公式。

加载时保留原来的 142 张实体纹理，另在内存中组合 140 种马匹毛色/花纹/盔甲纹理与 16 种驯服狼项圈颜色；原始图片文件不修改。项圈颜色来自原版 `EntitySheep.getDyeRgb`。马的纹理组合和模型本身分离。

## 姿态输入

已有 `headYaw/headPitch` 为相对身体的弧度；`limbSwing/limbSwingAmount`、`ageTicks`、幼体、潜行和基础 variant 保持原接口。新增 `flags` 为 `EntityPoseFlags`，包含坐下、生气、驯服、疾跑、悬挂、鞍、箱子、骑手、摇尾、远古守卫者、手臂/底座显示、饮用等模型状态。

常见专用输入：

- 狼：`health` 是原狼 data watcher 18 的尾姿态健康值；`collarColor` 为染料元数据 0–15。另提供感兴趣与四段甩水角度。
- 猫：variant 0 豹猫、1 黑猫、2 红猫、3 暹罗猫。
- 马：`horseType` 0 马、1 驴、2 骡、3 僵尸马、4 骷髅马；variant 低字节是毛色，高字节是花纹；`horseArmor` 0/1/2/3 为无/铁/金/钻石。提供进食、扬蹄、张嘴及幼体尺寸插值。
- 兔子：variant 0–5 为普通纹理、99 为杀手兔；`PoseToast` 选择 Toast。`jumpProgress` 为原跳跃插值。
- 女巫：实体 ID 和整数年龄参与鼻子摆动，`PoseDrinking` 控制持药水时鼻姿态。
- 守卫者：脊刺伸展、尾摆相位与眼偏移；远古状态应用 2.35 倍模型比例。
- 凋灵：无敌时间、两个侧头相对角；盔甲架：六组协议角度（度），底座使用身体 yaw 保持方向。
- 末影龙：动画相位和 24 组原 `getMovementOffsets` 的朝向/高度样本，驱动颈部、尾部、身体倾斜与双翼。

调用方未提供实体状态插值时，会使用基础姿态；守卫者尾摆和末影龙相位有明确的周期缺省值。存在接口不代表网络层已经把每一种状态全部接线。

## 验证范围

```powershell
python tests/assets_tests.py -k native_entity_meshes
python tools/verify_entity_models.py
```

公共接口测试覆盖全部 33 个生物类型、船/矿车/盔甲架、UV 范围、单位法线、网格顶点数量、纹理变体、基本动画、幼体比例与非法输入。

Java 姿态测试重新编译原始模型类并调用实际 `setLivingAnimations/setRotationAngles`，比较狼、猫、马、兔子、女巫、守卫者、凋灵、蝙蝠和盔甲架。**73 个场景、1,442 个关节快照通过**，最大绝对差 `2.9802322387695312e-08`，阈值 `2e-6`。包含坐姿、进食/扬蹄/鞍/箱子/骑手、兔子跳跃、守卫者脊刺、侧头和盔甲架协议角度。报告在 `build/entity_model_reference/pose_report.json`。

该快照验证关节变换，不是对每张 GPU 输出逐像素比较。末影龙的 GL 渲染路径不在这组关节快照中，其构造几何来源已导出，网格通过公共接口测试。守卫者光束、凋灵护甲效果、末影龙死亡/治疗光束，以及原先明确缺少的完整特殊层/透明挤压等仍需独立处理。船/矿车的受击摇晃、轨道姿态与矿车载荷未包含在本模块中；TNT/下落方块由方块图集对象渲染另行实现。

实体模型不替代物理命中箱。点击应使用 `entity_dimensions.hpp` 及相应元数据/特殊 AABB，详见 [选择与命中几何](PICKING.md)。本轮不实现实体 AI 或世界模拟。
