# 当前渲染与跑图内存测量

2026-10-10，最终构建 `bin/NativeVoxel-20261010-verified.exe`。硬件为 NVIDIA GeForce RTX 5060 Laptop GPU，OpenGL 3.3.0 NVIDIA 592.25。构建使用 GCC 8.3、`-O3 -ffp-contract=off -fno-fast-math`。

性能场景是服主授权取得的服务器数据在本地回放：441 个区块、41 个实体，当前视点约 1,305,970 个三角形，驻留 2,926 个区段。分辨率 1920 × 1080、12 区块视距，使用原版光照/AO；附加阴影、FXAA、垂直同步及 Secret Settings 均关闭。皮肤联网下载关闭。每帧 `glFinish`，测量包含 CPU 提交和 GPU 完成等待。

| 预热后样本 | 平均帧时间 | P50 | P95 | 平均 FPS |
|---:|---:|---:|---:|---:|
| 907 | 4.071 ms | 3.995 ms | 4.938 ms | 245.6 |

共运行 1200 帧，统计排除尚未完成网格准备的帧。动态部分有 18,048 个顶点、137 个绘制批次；动态准备平均 1.475 ms，网格维护平均 0.093 ms。原始报告为 `build/verified-benchmark-1080p.json`，图像为 `build/verified-server.ppm`。

这是同一捕获场景的静态回放结果，不代表在线跑图、复杂战斗或其他硬件的 FPS，也没有进行原版/OptiFine 同条件排名比较。

## 跑图缓存回收

真实 OpenGL 场景循环经过 160 站、640 列，使用 `PROCESS_MEMORY_COUNTERS_EX.PrivateUsage` 测量。预热后的 120 站中，完整测试进程私有内存从 248,025,088 到 251,293,696 字节，跨度 3,268,608 字节（3.12 MiB）；驻留网格峰值 4，卸载后的最终驻留网格为 0。另一次独立执行测得跨度 3.05 MiB。报告与完整输出在 `build/final-roaming-validation.log`、`build/projectile-finish/roaming_memory_report.json`。

CPU 包处理还运行了 2,000 次区块加载/卸载循环，最终 chunk/tile/sign 缓存均归零。修复包括视距外 GPU 网格淘汰、空图层释放、待处理网格上限 12、动态纹理回收、离场实体动画及皮肤请求清理，以及忽略已卸载区块的迟到方块/方块实体更新。

该测试用于检查是否随经过站点数持续累积内存；峰值仍会随视距、服务器区块内容、资源包和实体数量变化。它不把所有工作集波动都视为泄漏。

## 画面验证

4 组原 `GuiMainMenu` 绘制命令 GPU 回放覆盖宽屏、方形和竖屏，以及不同旋转时刻。最大颜色通道差为 2/255，平均差小于 0.0007/255，没有通道差超过 6 的像素。24 套原版 Secret Settings 的实际 GLSL 和 pass graph 均通过 GPU 测试，关闭后恢复正常帧。

即时方块光照在增删光源、拆封屋顶和跨区块传播后，与独立全量重算比较 1,441,792 个采样点，全部一致。流水连续性、石墙连接和 AO 另有针对检查。实体及屏幕测试覆盖水/火/岩浆、受击、死亡、背包模型跟随鼠标和 GL 状态恢复。
