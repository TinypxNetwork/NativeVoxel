# 本地世界接入

`LocalSession` 把 `Game`、`Simulation`、`worldio::SaveInfo` 和可选原生地形生成器连接起来。应用程序在本地调用 `local.tick(game, input, distance)`，在服务器会话中调用 `game.tick(input)`，不能在同一个逻辑刻同时调用二者。

## 世界创建与加载

创建操作先在临时对象里生成起始区域、选择出生点并安装本地模拟。无效设置或进度回调取消不会替换当前世界。当前游戏入口只接受未开启结构的 Carved 基础地形阶段，完整 population 尚未接入。

加载操作先读取 Anvil，再校验和恢复原生附加文件。损坏的附加文件不会部分替换活动世界。不存在附加文件时，从标准玩家 NBT 恢复背包、护甲、食物、经验、末影箱、飞行状态及支持的世界规则，并导入熔炉和酿造台。

玩家移动时每刻最多加载/生成两个缺失区块。已有 Anvil 文件优先于生成器。生成器只对含 `NativeVoxelBaseGeneration` 标记的原生存档重建；普通导入存档不猜测如何生成缺失地形。缺失原始区块会缓存查询结果。当前最多保留 8,192 个加载区块，尚未实现完整的后台读写和区块卸载。

## 容器

熔炉和酿造台保留独立的机器状态，关闭窗口前提交修改，在窗口关闭期间继续运行。新加载的标准 NBT 导入机器时不会覆盖已经从原生附加文件恢复的权威状态。保存时把最新物品和计时写回对应标准方块实体，并保留自定义名称等未知字段。

箱子、陷阱箱、发射器、投掷器和漏斗的储物内容保存在方块实体 NBT。双箱按原版 NORTH/EAST/SOUTH/WEST 遍历和 InventoryLargeChest 拼接规则排列。普通箱检查上方实心方块和已存在的坐姿豹猫；带 Lock 的箱子检查手持物品名称。末影箱共享玩家的 27 格 EnderItems。箱子开关向渲染层发布箱盖事件。

这些容器的储物界面已经接入，漏斗运输、发射、完整破坏掉物和所有高级容器机制仍未完成。未实现的权威破坏会被拒绝，不回退成客户端单独删除方块。

## 保存

快照写入同目录下独占创建的临时文件夹，完成 Anvil 和 `native_simulation.dat` 后再改名为最终新目录；拒绝覆盖现有目录。失败清理仅作用于本次创建且路径重新核验过的临时目录。

| 标准存档槽位 | 原生 Game 槽位 |
|---|---|
| 0–8 热键栏 | 36–44 |
| 9–35 主背包 | 9–35 |
| 100–103 靴子至头盔 | 8–5 |

保存之前关闭窗口并提交机器/储物修改。光标与临时合成输入遵循关闭规则成为原生掉落实体。删除的方块实体会生成明确的 TAG_End 更新，避免保留的旧 Anvil NBT 把它恢复出来。

标准 NBT 和原生附加文件目前存在明确的职责边界：原生掉落物/经验、随机数状态和其他额外模拟字段保存在附加文件里；尚未完成标准 Entities 的完整导入/更新。仅导出已加载的区块，未加载区域不会自动复制。

## 验证

`tests/local_session_tests.cpp` 的 89 项检查覆盖三个维度的创建、取消/无效设置、单刻推进、在线回调隔离、挖掘/拾取、机器关闭后运行、双箱/锁/末影箱/其他储物、原生与标准 NBT 恢复、世界边界、远区块编辑保留、删除记录和损坏存档的事务性。

还可生成用于图形检查的独立夹具：

```powershell
.\build\tests\local_session_tests.exe --export-visual build\new-visual-fixture 1
.\bin\NativeVoxel.exe --hidden --world build\new-visual-fixture --frames 180 --screenshot build\visual.ppm
```

目标目录必须尚不存在。夹具包含普通/末影箱、熔炉、旗帜、头颅、告示牌、掉落物、经验和透明持物；它是人工布置的验证场景，不作为原版地形生成证据。
